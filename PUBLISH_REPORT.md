## 🚨 Критические исправления безопасности

### 1. **Уязвимость с временными файлами (CVE-подобная)**
- **Проблема:** Небезопасное создание временных директорий в test_subscription.sh
- **Риск:** symlink attack, возможность подмены файлов
- **Решение:** 
  - Добавлен trap для автоматической очистки
  - Создан безопасный скрипт mktemp_secure.sh
  - Все временные файлы теперь создаются с правами 700

### 2. **Некорректная обработка переменных прокси**
- **Проблема:** Несоответствие `service_proxy_address` и `http_proxy_address` в list_update()
- **Риск:** Прокси не использовался при проверке GitHub
- **Решение:** Исправлено имя переменной во всех местах использования

### 3. ** Injection через UCI операции**
- **Проблема:** Отсутствие валидации connection_type
- **Риск:** Возможность инъекции команд через uci show
- **Решение:** Добавлена whitelist валидация для connection_type

## 🛡️ Улучшения безопасности и стабильности

### 4. **Улучшенная генерация случайных ID**
```bash
# До (слабая энтропия):
printf '%s%s' "$(date +%s)" "$RANDOM" | md5sum | cut -c1-16

# После (криптографически стойкая):
```

## 🚀 Подготовка к сборке

### Параметры сборки:
- **Архитектуры:** all (для luci-app), x86_64, arm64, mips, aarch64
- **Зависимости:** sing-box ≥1.12.0, jq ≥1.7.1, coreutils-base64 ≥9.7
- **Требования:** OpenWrt 25.xx, ash shell, nftables

### Скрипт сборки:
```bash
#!/bin/bash
# build_obhod.sh
export SDK_PATH=/path/to/openwrt-sdk
./scripts/build.sh x86_64
./scripts/build.sh aarch64
./scripts/build.sh mips
```
