# 💡 Идеи для развития: Obhod v1.1.x "Ultra-Intelligence"

После успешного релиза v1.0.0, проект готов к переходу на уровень корпоративных решений. Вот основные идеи для следующего этапа апгрейда:

## 1. 🚀 Latency-Based Steering (Интеллектуальный выбор пути)
Сейчас `urltest` в sing-box работает хорошо, но он реактивен. 
*   **Идея**: Добавить в Go-демон `obhod` модуль мониторинга качества канала (Jitter, Packet Loss).
*   **Результат**: Если основной туннель начинает "лагать" (даже если он пингуется), система превентивно переключит критический трафик (например, Zoom или игры) на резервный, более стабильный туннель.

## 2. 🌍 Local Geo-Data Management
Зависимость от внешних `.srs` списков — это риск.
*   **Идея**: Внедрить поддержку локальных баз данных GeoIP и GeoSite (MaxMind/v2ray формат) с автоматическим еженедельным обновлением.
*   **Результат**: Возможность писать правила вида "Весь Китай — напрямую, вся Европа — через прокси A, всё остальное — через прокси B" без скачивания сотен отдельных файлов.

## 3. 🔒 Killswitch 2.0 (Firewall Hardening)
Текущая маршрутизация надежна, но не гарантирует 100% блокировку при критических сбоях ядра.
*   **Идея**: Реализовать режим "Strict Isolation" через nftables. 
*   **Результат**: Если демон обнаруживает, что `sing-box` упал и не может подняться за 10 секунд, роутер полностью блокирует исходящий трафик для выбранных устройств, исключая любую возможность утечки данных через провайдера.

## 4. 📱 Obhod Mobile API & Webhook
*   **Идея**: Добавить легковесный REST API в `obhod` и поддержку Webhooks.
*   **Результат**: 
    *   Возможность создать мини-приложение для телефона или виджет для рабочего стола для переключения прокси.
    *   Отправка уведомлений не только в Telegram, но и в Home Assistant или другие системы умного дома.

## 5. ⚡ Протоколы нового поколения
*   **Идея**: Добавить поддержку **TUIC v5** и **Juicity** в Go-генератор.
*   **Результат**: Улучшение работы в условиях жестких ограничений (высокий пинг, нестабильные сети).
