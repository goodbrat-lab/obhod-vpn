# Obhod — Умная точечная VPN-маршрутизация для OpenWrt 25.xx

**Obhod** — современный, надежный и стабильный инструмент для выборочной маршрутизации трафика на роутерах под управлением OpenWrt 25.xx (и старше). Проект является идейным наследником проекта Podkop, переписанным с нуля на Go и Bash для решения фундаментальных проблем стабильности.

Текущая стабильная версия: `1.1.38`

---

## 🚀 Почему Obhod, а не Podkop?

Obhod решает критические архитектурные недостатки оригинала, которые приводили к потере DNS и отсутствию интернета после перезагрузки роутера (особенно при внезапном отключении питания):

1. **Интеллектуальный старт (Без гонки сервисов)**: Демон ожидает полноценного поднятия WAN-интерфейса и проверяет сетевую связность перед запуском `sing-box`. Это исключает ситуации, когда DNS-резолвер стартует до готовности сети и падает с фатальной ошибкой.
2. **Watchdog и автовосстановление**: Нативный Go-watchdog каждые 30 секунд проверяет здоровье DNS и прокси-соединения. При обнаружении трех последовательных сбоев сервис автоматически перезапускается.
3. **Умное управление кешем FakeIP**: При перезагрузке роутера демон принудительно сбрасывает зависший кеш `dnsmasq`, предотвращая разрыв установленных соединений на клиентских устройствах.
4. **Безопасная валидация конфигов**: Генератор конфигурации JSON написан на Go и исключает ошибки синтаксиса, свойственные склеиванию строк в shell. Перед применением конфигурации выполняется её валидация встроенными средствами.
5. **Совместимость с mwan3**: Динамическое распределение `fwmark` предотвращает любые конфликты маршрутизации.

## 🛠️ Возможности

- **Поддержка протоколов**: VLESS (с поддержкой Reality и TLS), VMess, Shadowsocks, Trojan, Hysteria2 и SOCKS.
- **Поддержка WS & gRPC**: Современные транспорты с 0-RTT/Early Data для обхода цензуры.
- **DNS через прокси (DoH/DoT)**: Полное шифрование DNS-запросов через выделенный detour с поддержкой bootstrap-резолвера для доменных DoH-серверов.
- **Множественные туннели**: Возможность настройки независимой маршрутизации для разных прокси/интерфейсов.
- **Удобная диагностика**: Встроенная интеграция с Clash WebSocket API и современная веб-панель управления (Yacd) прямо в LuCI.

## 📦 Быстрая установка

Для установки или обновления выполните команду в консоли роутера:
```bash
sh <(wget -O - https://github.com/goodbrat-lab/obhod-vpn/raw/main/install.sh)
```

Инсталлятор автоматически определит архитектуру вашего процессора, проверит системные требования (`sing-box >= 1.12.0`, `nftables`, `dnsmasq-full` или аналоги) и установит пакеты:
- Бэкенд и демон: `obhod_1.1.38-1_<arch>.ipk`
- Интерфейс LuCI: `luci-app-obhod_1.1.38-1_all.ipk`

После установки веб-интерфейс будет доступен по пути **Services -> Obhod** в LuCI.

## 🔍 Диагностика

- Просмотр логов в реальном времени:
  ```bash
  logread -f -e obhod
  ```
- Статус службы:
  ```bash
  /etc/init.d/obhod status
  ```
- Включение отладочного режима:
  ```bash
  uci set obhod.settings.log_level='debug'
  uci commit obhod
  /etc/init.d/obhod restart
  ```

## 🏗️ Сборка проекта

Сборка всех пакетов выполняется в Linux-окружении с установленным OpenWrt SDK:

1. Установите переменную окружения `SDK_PATH` на директорию с вашим OpenWrt SDK:
   ```bash
   export SDK_PATH=/path/to/openwrt-sdk
   ```
2. Запустите скрипт сборки:
   ```bash
   ./scripts/build_all.sh
   ```

Скрипт автоматически соберет Go-демон под архитектуры `mipsel_24kc`, `mips_24kc`, `aarch64_cortex-a53`, `arm_cortex-a7_neon-vfpv4`, `x86_64` и упакует их в `.ipk` файлы внутри директории `dist/packages/`.
