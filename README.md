# Obhod: Профессиональная VPN-маршрутизация для OpenWrt

**Obhod** — это современный, мощный и стабильный программный комплекс для выборочной маршрутизации трафика на роутерах под управлением OpenWrt 25.xx.

![Obhod Dashboard](https://via.placeholder.com/800x400?text=Obhod+Professional+Dashboard+v1.0.0)

## 🚀 Ключевые возможности v1.0.0

*   **⚡ Go-Powered Core**: Высокопроизводительное ядро на Go для генерации конфигураций и мониторинга. Работает до 10 раз быстрее старых Bash-решений.
*   **🛤️ Multi-Tunnel & Multi-List**: Поддержка нескольких одновременных туннелей. Направляйте YouTube через один прокси, а Telegram через другой.
*   **🛡️ DNS Detouring**: Умная маршрутизация DNS-запросов через соответствующие туннели для предотвращения утечек и обхода блокировок на уровне резолвинга.
*   **📊 Live Dashboard**: Графики скорости трафика в реальном времени, статистика соединений и индикатор «здоровья» системы.
*   **🤖 Telegram Integration**: Мгновенные уведомления в ваш мессенджер при падении туннелей или смене внешнего IP.
*   **🪄 Auto-Setup Wizard**: Мастер первой настройки, который сам определит параметры вашей сети и предложит оптимальную конфигурацию.
*   **💾 Backup & Restore**: Легкий экспорт и импорт всех настроек для миграции между роутерами.
*   **🗜️ RAM Optimized**: Поддержка бинарных списков `.srs` и вынос пользовательских правил во внешние файлы для работы на устройствах с малым объемом памяти.

## Быстрый старт

Установите **Obhod Professional** одной командой:

```bash
sh <(wget -q -O - https://raw.githubusercontent.com/goodbrat-lab/obhod-vpn/main/install.sh)
```

## Разница с другими решениями
Obhod — это не просто скрипт, а полноценный демон-супервизор, который гарантирует, что ваш VPN будет работать стабильно даже после скачков напряжения или сбоев провайдера. В отличие от Podkop, Obhod использует нативную компиляцию правил и имеет встроенную защиту от невалидных конфигураций.

## Диагностика и Логи

Obhod оснащен продвинутой системой логирования для быстрого поиска проблем:
1.  **Вкладка Logs**: Просматривайте логи в реальном времени прямо в LuCI. Поддерживается фильтрация по уровням (DEBUG, INFO, ERROR).
2.  **Syslog**: Все события записываются в системный журнал OpenWrt. Чтение через консоль: `logread -e obho[ud]`.
3.  **Debug-режим**: Если что-то не работает, включите расширенное логирование в LuCI (Settings -> Log Level) или через консоль:
    ```bash
    uci set obhod.settings.log_level='debug'
    uci commit obhod
    /etc/init.d/obhod restart
    ```

## Разница с Podkop
Obhod был написан с нуля, чтобы решить фундаментальные проблемы оригинального Podkop:
1.  **Потеря DNS после перезагрузки**: Obhod отслеживает состояние DNS и перезапускает прокси автоматически.
2.  **Зависание FakeIP**: Принудительная очистка кеша при старте.
3.  **Сложность настройки**: Больше никаких консольных правок JSON — всё делается через браузер.
