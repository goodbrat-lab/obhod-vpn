# Obhod: Умная VPN-маршрутизация для OpenWrt

**Obhod** — это мощный и стабильный инструмент для выборочной маршрутизации трафика на роутерах под управлением OpenWrt 25.xx. Проект создан для тех, кому важна бесперебойная работа VPN и корректное восстановление связи после внезапных отключений питания.

![Obhod Dashboard Placeholder](https://via.placeholder.com/800x400?text=Obhod+LuCI+Interface+Status+Page)

## Основные преимущества

*   **Надежность**: Бэкенд на Go с активным мониторингом здоровья DNS и туннелей.
*   **Умный запуск**: Защита от "гонки сервисов" — стартует только когда интернет реально доступен.
*   **Простая настройка**: Полностью графический интерфейс в LuCI для управления туннелями и доменами.
*   **Эффективность**: Минимальное потребление ресурсов и корректная работа с `nftables` и `mwan3`.
*   **Поддержка протоколов**: VLESS, WireGuard и другие (через ядро sing-box).

## Быстрый старт

1.  Установите пакеты `obhod` и `luci-app-obhod`.
2.  Откройте в браузере: `http://192.168.1.1/cgi-bin/luci/admin/services/obhod`.
3.  Добавьте ваш первый туннель и список доменов.
4.  Наслаждайтесь свободным интернетом.

Подробная инструкция по установке доступна в [INSTALL.md](./INSTALL.md).

## Разница с Podkop

Obhod был написан с нуля, чтобы решить фундаментальные проблемы оригинального Podkop:
1.  **Потеря DNS после перезагрузки**: Obhod отслеживает состояние DNS и перезапускает прокси автоматически.
2.  **Зависание FakeIP**: Принудительная очистка кеша при старте.
3.  **Сложность настройки**: Больше никаких консольных правок JSON — всё делается через браузер.
